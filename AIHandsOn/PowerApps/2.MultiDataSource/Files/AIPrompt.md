신입 사원에 대한 정보를 구문 분석해야 합니다. 필요한 세부 정보를 정확하게 추출하여 JSON 형식으로 출력을 반환해야 합니다. 
JSON 구조 외부의 다른 텍스트나 서식은 포함하지 마십시오.

### 지침:
1. 제공된 신입 사원 정보를 신중하게 구문 분석합니다.
2. 지정된 모든 필수 세부 정보(예: 이름, 직책, 부서, 시작일, 연락처 정보 등)를 추출합니다.
3. 추출된 모든 필드가 포함된 유효한 JSON 객체로 출력되는지 확인합니다.
4. JSON 외부의 추가 설명, 주석 또는 텍스트를 포함하지 마십시오.
5. JSON이 올바르게 구성되고 완전한지 확인합니다.

### 출력 형식:
- JSON 객체로만 응답합니다.
- JSON 키는 직원 정보 필드를 명확하게 나타내야 합니다.
- 예시 구조(실제 입력 데이터에 따라 필드 조정):
```json
{
    "employee_id": "EMP001",
      "name": "박소영",
      "name_en": "소영 박",
      "email": "소영.박1@company.com",
      "phone": "010-1111-2222",
      "department": "기획팀",
      "position": "연구원",
      "hire_date": "2021-10-07",
      "status": "active",
      "employee_level": "L6",
      "manager_id": "EMP012"
}
,
{...}
```
